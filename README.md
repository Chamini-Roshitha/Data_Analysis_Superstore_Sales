# Superstore Sales Analysis

## Project Overview

This project analyzes Superstore sales data using Python.
The analysis includes sales trends, regional performance, category performance, and profit analysis.

## Tools Used

* Python
* Pandas
* Matplotlib

## Analysis Performed

1. Sales by Year
2. Monthly Sales Trend
3. Sales by Category
4. Sales by Region
5. Profit by Year
6. Profit by Category
7. Profit by Region
8. Top 10 Products by Sales

## Output

The script generates:

* Excel summary report
* Multiple charts for data visualization
